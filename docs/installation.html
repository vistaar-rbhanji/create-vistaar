Installation

Prefer npx for one-off scaffolds. Install globally when you use Vistaar often.

Using npx

No permanent install required. Always runs a recent published version:

npx create-vistaar

Using npm

Install the package, then run the binaries from your shell:

npm install -g create-vistaar
create-vistaar
vistaar doctor

Global installation

npm install -g create-vistaar

This exposes both create-vistaar (scaffold) and vistaar (manage).

Local installation

Useful inside a monorepo or when developing the CLI itself:

npm install create-vistaar --save-dev
npx create-vistaar
npx vistaar doctor

For contributors: clone the repo, run npm install, then npm run build and npm link.

Updating

npm update -g create-vistaar
# or
npm install -g create-vistaar@latest

Uninstalling

npm uninstall -g create-vistaar
