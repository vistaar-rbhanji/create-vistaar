CLI Reference

Two binaries: create-vistaar creates projects; vistaar manages them.

create-vistaar

Interactive project scaffolding. Collects stack choices and generates the workspace.

npx create-vistaar
# or after a global install
create-vistaar

Typical prompts include project name, language, UI framework, backend, database, ORM, auth, Docker, Git, Husky, and ESLint/Prettier.

vistaar doctor

Runs project health checks when a generated scripts/doctor.js is present.

cd my-app
vistaar doctor

Run doctor from the project root so it can locate setup markers and scripts.

vistaar add 🚧 Coming Soon

vistaar add auth

vistaar generate 🚧 Coming Soon

Generate CRUD resources and related boilerplate inside a project.
