Open-source scaffolding CLI

Build Production-Ready Applications in Minutes

Vistaar is an open-source project scaffolding CLI that helps developers create modern full-stack applications from a single command.

Get Started GitHub
$ npx create-vistaar

Everything you need to start

Pick your stack once. Vistaar scaffolds frontend, backend, database, Docker, and modules.

R

React

Vite-powered React apps with TypeScript or JavaScript.

E

Express

Node backends with typed routes and health checks.

F

FastAPI

Python APIs when you want a FastAPI backend.

P

PostgreSQL

Prisma or Drizzle ORM templates ready to migrate.

M

MongoDB

Mongoose models and seed scripts out of the box.

D

Docker

Compose files for local multi-service development.

A

Authentication

Optional auth module wired into your generated stack.

H

Health Check

Live API health and setup status from day one.

C

CLI Tools

create-vistaar to scaffold, vistaar to manage.

CLI Preview

Scaffold a project, then diagnose it with the management CLI.

cd my-app
npm run dev
