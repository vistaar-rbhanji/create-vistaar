Getting Started

Go from zero to a runnable full-stack app with one interactive command.

What is Vistaar

Vistaar is an open-source scaffolding CLI. It asks a few questions about your stack, then generates a production-oriented project layout — frontend, optional backend and database, Docker, modules, and setup tooling — from reusable templates.

Why use it

  • Consistent project structure across teams
  • Opinionated defaults for React, Express/FastAPI, and popular databases
  • Optional modules (auth, Docker) without reinventing plumbing
  • Built-in doctor and setup wizard for a smoother first run

Requirements

  • Node.js 18 or newer
  • Git (recommended for version control and husky hooks)

Python is only required if you choose a FastAPI backend.

Quick Start

npx create-vistaar

Answer the prompts, then enter the generated folder and start the apps.

First Project

  1. Run npx create-vistaar and choose a project name.
  2. Select frontend language, UI kit, backend, and database options.
  3. Optionally enable authentication, Docker, Git, Husky, and ESLint/Prettier.
  4. Open the generated README for stack-specific next steps.
  5. Run vistaar doctor if something looks off.
cd my-app
npm install
npm run dev
